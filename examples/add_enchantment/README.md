# Add an Inscribed ritual

Install this folder, or a ZIP containing its `pack.mcmeta` at the archive root, into the world's `datapacks` directory and run `/reload`.

It adds `example:sharpness_1`. It does not replace Inscribed's original Sharpness recipe and is not installed with the mod by default. Remove the example pack after testing if you do not want an additional alternative recipe in your world.

Read [the authoring tutorial](../../docs/ADDING_ENCHANTMENTS.md), or [em português](../../docs/ADDING_ENCHANTMENTS.pt-BR.md), before changing enchantment IDs, levels or ingredients. Contents are covered by the repository's MIT license.
