# Official Inscribed default datapack

This is production content, not an example. It is the single source for the bundled default data and generated configuration exports. Minecraft 1.21.1, Inscribed 0.7.2. Create content is conditional.

The mod already includes this pack's data. Installing the separate ZIP is optional and replaces the same resource IDs; it does not add duplicate active recipes. Config overlays still take precedence. Use this pack as an official content artifact or override baseline, not alongside renamed copies of its recipes.

All 42 supported vanilla enchantments and both Create enchantments have every valid level and both Infusion/Extraction. No intentional exclusions. Maximum eight unit ingredients per mode; one item per pedestal. The historical `inscribed:test_sharpness_1` ID is retained as the canonical Sharpness I recipe to preserve discovery/save/config references. It is production content, not a debug fixture.

The Gradle build generates the default JSON config mirrors from these files. Do not edit generated build outputs. Example datapacks and test resources are separate and are never automatically included here.
