## Short - CurseForge, Modrinth and GitHub

Physical enchanting with books, libraries and pedestal reagents. Infuse or extract enchantments through data-driven rituals, with optional JEI, LSBC and Create support.

## Long - CurseForge and Modrinth

Enchanted Books are physical knowledge. Build a library in Chiseled Bookshelves, gather reagents on Infusion Pedestals and use an Enchanting Table to apply or extract enchantments. Rituals use Bookshelf Power and materials instead of XP or lapis. Discovery never replaces the physical reference book.

Includes a Guide Book, vanilla progression recipes, conditional Create recipes, Catalyst structure loot and configurable extraction risk. JEI shows eligible rituals; LSBC optionally adds Codex discovery names and magnifying-glass inspection. Book and Quill provides inspection without LSBC.

Recipes and loot support datapacks, with global settings and compatible JSON overlays for modpacks. Requires Minecraft 1.21.1, NeoForge 21.1.255 or newer and Java 21. Optional JEI/LSBC/Create. Default extraction failure is 20%. Consult documentation for anvil rules, automation limits and config precedence.
