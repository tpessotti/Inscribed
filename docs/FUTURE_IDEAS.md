# Future ideas - outside the frozen candidate

These are backlog ideas, not implemented release features:

- Merchant/trade overhaul and Rust/Bust integration.
- EMI/REI support.
- Custom ritual sound pack and richer particles.
- Additional catalyst variants, discovery items and advanced ritual types.
- New enchantments, relics and custom world generation.
- A stable addon API and independent client visual configuration.

The candidate priority is stability, clarity, compatibility and polish. Gameplay expansion starts after this release cycle.
