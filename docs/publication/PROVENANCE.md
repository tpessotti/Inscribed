# Development and media provenance

The project owner supplied direction, concept and testing feedback. Codex generated substantial implementation and documentation. Some bundled raster assets, including the temporary Enchantment Catalyst sprite, were produced with an image-generation model. Their earlier provenance is retained in the repository credits and visual-update records. These contributions must not be represented as entirely hand-authored code or artwork.

The public presentation uses **real Minecraft screenshots**, captured from a separate local Minecraft 1.21.1 / NeoForge client running the packaged Inscribed mod. They are not AI illustrations, mockups or edited representations of gameplay. The native preview constructs a demonstration altar and supplies materials in a disposable world. Its camera can fly and the preview player is protected; these images demonstrate the actual renderer and ritual, not an unaided survival playthrough. The merchant image shows the actual vanilla trade interface, followed by a server-verified purchase. The icon is a native render of the mod's pedestal. Capture files are copied without image synthesis or retouching.

No optional mod or resource pack is required by the preview. Its QA module is excluded from the release JAR. Screenshots do not imply a new structure generator or automatic altar construction feature in the production mod.
